# Global Superstore Sales Analysis

## Project Overview

An interactive Business Intelligence dashboard developed using Microsoft Power BI to analyse Global Superstore sales data.

## Project Objectives

- Analyse overall sales and profit.
- Analyse monthly sales and profit trends.
- Compare regional performance.
- Analyse category-wise profit contribution.
- Identify the top 10 cities based on sales.

## Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX
- Global Superstore Dataset

## Dashboard KPIs

- Total Sales: 12.64M
- Total Profit: 1.47M
- Profit Margin: 11.61%
- Total Customers: 2K
- Total Orders: 25.035K

## Dashboard Features

- Revenue Trend Analysis
- Regional Profitability Matrix
- Revenue Composition by Geography
- Profit Contribution by Category
- Top 10 Cities Based on Total Sales
- Interactive Year, Segment, Region and Category filters

## Key Business Insights

- Technology contributes the highest share of category-wise profit (45.23%).
- Office Supplies contributes 35.33%.
- Furniture contributes 19.44%.
- New York City is the highest-performing city by sales.
